Общие требования 
 
Технические и архитектурные требования 
 
Приложение должно быть реализовано с использованием следующих технологий: 
− Язык программирования: Kotlin; 
− Интерфейс пользователя: Jetpack Compose и Material Design 3; 
− Архитектурные подходы:  
a) Разделение обязанностей между интерфейсом пользователя и бизнес-
логикой должно быть реализовано с помощью паттерна MVVM 
(Model-View-ViewModel); 
b) Взаимодействие между View и ViewModel должно быть строго 
циклическим и однонаправленным (концепция UDF); 
− Работа с реляционной БД: Room и Kotlin Flow; 
− Вспомогательные хранилища: Realm, Jetpack DataStore и kotlinx.serialization 
для сериализациия JSON-файлов; 
− Сетевые запросы: Retrofit и OkHttp; 
− Асинхронность: Kotlin Coroutines и Kotlin Flow; 
− Работа с камерой: CameraX и Google ML Kit для распознования штрихкодов и 
текстов на изображении; 
− Сборщик проекта: Gradle. 
 
В заданиях, где данные получаются через REST API , нет необходимости 
реализовывать собственный сервис. Допускается создать mock-сервер в Postman (или 
другим аналогичным способом) или использовать любой открытый API-сервис, 
подходящий по тематике задания.

4. Управление данными:  
− Распознанное слово передается в реактивный поток данных Kotlin Channels 
(или StateFlow). Если слово присутствует во встроенном словаре, карточка 
заполняется автоматически.  
− Алгоритм интервальных повторений (SuperMemo SM-2) вычисляет точную 
дату следующего показа слова и модифицирует очередь в базе данных.  На 
основе обновленной выборки система агрегирует целевые записи, 
аннулирует неактуальные задачи в системном планировщике 
AlarmManager и регистрирует новый триггер в службе локальных Push-
уведомлений на расчетное время повторения. 
5. AI-функция: 
− Генератор примеров – пользователь вводит слово (или сканирует его), а 
приложение с помощью LLM создаёт 3 новых примера предложений на 
изучаемом языке с переводом. Примеры адаптированы под уровень 
пользователя: для начинающих – простые конструкции, для продвинутых 
– сложные. 
Пример промпта:  Ты – преподаватель английского. Слово ephemeral. 
Уровень: Intermediate (B1) . Придумай 3 примера предложений на 
английском с переводом и кратким пояснением. Разной сложности: 
простое, среднее, сложное. 
6. Голосовой интерфейс: 
− Пользователь голосом произносит иностранное слово для проверки, а 
приложение озвучивает правильный перевод и пример использования. 
 
Архитектурные особенности приложения 
В качестве централизованного механизма внедрения зависимостей для всех 
архитектурных слоев приложения должен быть использован фреймворк Koin.

В работе должен быть реализован следующий подход к хранению информации:

работы.
