# Как передать приложение на телефон, запустить и проверить

## Что где лежит

| Файл | Размер | Зачем |
|---|---|---|
| `dist/FinancePlanner-lab5-6.apk` | ~28 МБ | **рекомендуемый** вариант: приложение без модели, модель выбирается на телефоне |
| `dist/FinancePlanner-lab5-6-with-model.apk` | ~1.1 ГБ | всё в одном: модель внутри APK, при первом запуске копируется в память приложения |
| `app/model-assets/models/qwen2.5-1.5b-instruct-q4_k_m.gguf` | ~1.07 ГБ | сама модель (нужна для первого варианта) |
| `docs/LR5_Отчёт_FinancePlanner.docx` | ~0.15 МБ | отчёт по ЛР №5 |
| `docs/LR6_Отчёт_FinancePlanner.docx` | ~0.15 МБ | отчёт по ЛР №6 |

---

## Вариант А (рекомендуемый): APK 28 МБ + модель отдельным файлом

Плюсы: APK ставится за секунды, модель читается прямо из «Загрузок» и не занимает
вторую копию во внутренней памяти.

### Шаг 1. Перекинуть на телефон два файла

**Способ 1 — по кабелю (Android File Transfer / Finder):**

1. Подключить телефон кабелем, на телефоне выбрать режим «Передача файлов (MTP)».
2. На Mac открыть **Android File Transfer** (или Finder → телефон).
3. Скопировать в папку телефона **Download**:
   - `dist/FinancePlanner-lab5-6.apk`
   - `app/model-assets/models/qwen2.5-1.5b-instruct-q4_k_m.gguf`

**Способ 2 — через adb (если установлен Android SDK):**

```bash
adb push dist/FinancePlanner-lab5-6.apk /sdcard/Download/
adb push "app/model-assets/models/qwen2.5-1.5b-instruct-q4_k_m.gguf" /sdcard/Download/
```

**Способ 3 — облако:** залить оба файла в Google Drive / Яндекс.Диск и скачать на телефоне.

### Шаг 2. Установить APK

1. Открыть на телефоне «Файлы» / «Загрузки» → нажать на `FinancePlanner-lab5-6.apk`.
2. Телефон спросит разрешение на установку из этого источника — разрешить
   («Настройки» → «Установка неизвестных приложений» → включить для «Файлов»/«Chrome»).
3. Нажать «Установить» → «Открыть».

### Шаг 3. Выбрать модель в приложении

1. Внизу экрана открыть вкладку **«Ассистент»**.
2. В карточке «5.1. Локальная LLM» нажать **«Выбрать GGUF-файл»**.
3. В системном диалоге: меню (☰) → **Downloads** → выбрать
   `qwen2.5-1.5b-instruct-q4_k_m.gguf`.
4. Появится «Модель загружена за N с» и зелёный бейдж **«AI офлайн»**.
   Выбор запоминается: при следующем запуске ничего выбирать не нужно.

> Файл должен лежать в памяти телефона (Download, Documents и т.п.), а не в облаке:
> приложению нужен локальный доступ к 1 ГБ данных.

## Вариант Б: всё в одном APK

1. Перекинуть на телефон `dist/FinancePlanner-lab5-6-with-model.apk` (~1.1 ГБ).
2. Установить так же, как в варианте А. Перед установкой проверить, что свободно
   **минимум 2.5 ГБ** (сам APK + копия модели во внутренней памяти).
3. Открыть «Ассистент» — приложение само скопирует модель из APK (прогресс-бар
   «Копируем модель из APK: N%»), затем загрузит её. На телефоне это занимает 1–3 минуты,
   на эмуляторе — несколько секунд.

## Проверка (чек-лист)

Открыть «Ассистент» и убедиться, что:

- [ ] зелёный бейдж **«AI офлайн»** и строка «Модель загружена за N с»;
- [ ] в строке модели написано `qwen2.5-1.5b-instruct-q4_k_m.gguf · 1065 МБ`;
- [ ] «Устройство: arm64-v8a · ОЗУ X ГБ · свободно Y ГБ» без красных сообщений.

Затем:

1. Нажать **«Добавить демо-операции»** (карточка «Демо-данные» внизу) —
   в базу добавятся траты за текущий и прошлый месяц.
2. Нажать **«Сформировать отчёт»** — кнопка сменится на «Анализ…», появится
   «Модель печатает… N токенов», текст отчёта будет появляться постепенно (20–60 с).
3. Нажать «Сформировать отчёт» ещё раз — отчёт вернётся **мгновенно** с бейджем
   «Отчёт из кэша» (кэш в Room).
4. Кнопка **«🔊 Озвучить»** — телефон прочитает отчёт (TextToSpeech), рядом появится «Стоп».

### Голос: добавление траты

1. Нажать **«🎤 Добавить трату голосом»** → разрешить доступ к микрофону.
2. Сказать: **«потратила двадцать пять рублей на такси»**.
3. Ожидаемо: строка «Распознано: …», затем «Трата 25,00 BYN сохранена • категория «Такси» •
   остаток баланса …», и эта же фраза озвучивается.

### Голос: показания счётчика

1. Выбрать чип **«Электроэнергия»** (или назвать тип голосом).
2. Нажать **«🎤 Продиктовать показания»**, сказать:
   **«электроэнергия тысяча двести пятьдесят»**.
3. Ожидаемо: показание сохраняется, в блоке счётчиков появляется строка
   «Электроэнергия · 1 250 кВт·ч», а приложение озвучивает:
   «Разница с прошлым месяцем: плюс 42 киловатт-часа» (если за прошлый месяц показание есть)
   либо «Это первые показания, сравнивать пока не с чем».

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| «Архитектура … не поддерживается» | телефон/эмулятор не arm64. Нужен реальный arm64-телефон либо arm64-эмулятор |
| «Модель не загрузилась за 120 с» | мало ОЗУ: закрыть приложения, перезагрузить телефон; проверить, что файл не повреждён (должен быть ~1.07 ГБ) |
| «Файл «…» не похож на GGUF-модель» | выбран другой файл; нужен именно `qwen2.5-1.5b-instruct-q4_k_m.gguf` |
| «Сначала загрузите GGUF-модель» | нажать «Выбрать GGUF-файл» и дождаться зелёного бейджа |
| «На устройстве нет службы распознавания речи» | установить «Речевые сервисы Google» / включить голосовой ввод в настройках языка и ввода |
| «Русский голос не установлен» | Настройки телефона → «Синтез речи» (Google TTS) → установить русский язык |
| «Микрофон занят» | закрыть приложение, которое держит микрофон (диктофон, звонок), повторить |
| Отчёт очень длинный / долгий | так работает модель 1.5B; можно нажать «Заново» или дождаться — предел ~300 с |
| Нужно освободить память | «Ассистент» → «Выгрузить» (освобождает ~1.2 ГБ) |

Логи (если подключён adb):

```bash
adb logcat | grep -E "LlmRepository|RNLlama|VoiceRepository|AndroidRuntime"
```

## Для отчёта

- Скриншоты лежат в `docs/screenshots/` (их же использует README).
- Отчёты: `docs/LR5_Отчёт_FinancePlanner.docx`, `docs/LR6_Отчёт_FinancePlanner.docx`
  (каждый < 0.3 МБ, загружаются на сайт без проблем).
- В отчётах нужно заполнить: ФИО, группу и ссылку на GitHub-репозиторий.
- Для GitHub: загрузить проект, **не** добавляя `app/model-assets/models/*.gguf`
  (1.1 ГБ, GitHub не примет) — модель распространяется отдельно, об этом написано в README.
